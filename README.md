# GroundPaint

ver 1.0 (11.06.2026)

Dependencies: LibAddonMenu-2.0

---

* How far can I go to damage with my BEAM?
* Why did the tank get NO heal???
* How to proc this duck-duck Alkosh???

Sounds familiar, doesn't it?

Sometimes it really *is* about positioning.
And during HOT fights it is not always easy to estimate where exactly you should stand.

## That's why I made this addon.

## What it CAN do:

* Draw a cartesian or radial grid attached to your character
* Draw your customized AoE and save it
* Draw predefined AoEs for selected skills and setups
* Save settings per character or account-wide
* Toggle visibility with a keybind

## What it CANNOT do:

* Recognize your sets and active skills (I am too lazy :P)
* Automatically improve your damage (you still have to move yourself)
* Tell you where to stand (it only draws stuff)

---

This addon was made mainly for myself (and inspired by some of my teammates).

That's why the database currently contains only a few presets.

But if you think something useful should be added — feel free to request it 🙂
